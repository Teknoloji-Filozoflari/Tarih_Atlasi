# Ham veri karantinası

Bu dizin boştur. Büyük veri indirilmez. Gelecekte izinli pilot girdiler buraya
değiştirilmeden alınabilir; dosyalar Git'e eklenmez. Lisans kararı çıkmadan ham
dosyaları veya dönüştürülmüş geometrileri yeniden dağıtmayın. `data/staging` yalnız
manifest/inceleme alanıdır; `etl build` bütün kapılardan geçmeden üretim yazmaz.
