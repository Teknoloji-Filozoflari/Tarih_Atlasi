```sh

```

yılın siyasi kayıtları** ya da arama üzerinden Türkiye Cumhuriyeti'ni açın.

Yerel dosyalardan tekrar üretme (geliştirici):

```sh
npm run data:download -- --verify
npm run polities:check-source
npm run physical:prepare
npm run pilot:prepare
npm run chunks:prepare
npm run check
```

kullanır. Uygulama bunu istemez; yayımlanan küçük çıkarım ve üretilmiş paketler
ile çalışır. Yeni dosya/hash/sürüm hazırlayıcıya otomatik onay verilmez.
